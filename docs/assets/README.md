As imagens preservam a interface capturada, sem geração artificial, reconstrução de tela ou alteração dos dados exibidos. Foram obtidas por navegação e consulta, sem criar solicitações, confirmar etapas, enviar e-mails ou acionar reset.

As capturas mostram o enquadramento disponível no navegador. Conteúdos em áreas de rolagem podem continuar abaixo da imagem. Datas, números de solicitação e indicadores variam conforme o reset e a atividade dos visitantes.

Para substituir imagens, utilize somente dados fictícios. Não inclua credenciais, tokens, e-mails reais, informações institucionais específicas ou telas de configurações privadas.
